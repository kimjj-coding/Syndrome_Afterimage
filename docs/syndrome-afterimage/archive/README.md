# 보관 문서 안내

이 폴더에는 이전 요약 또는 초안 중 참고 가치가 있는 문서를 보관한다. 과거 문서는 현재 상태를 자동으로 덮어쓰지 않는다.

- 현재 판단은 상위 문서 허브, 프로젝트 상태, 상세 통합 보고서와 근거 기록을 우선한다.
- 오래된 문서와 현재 문서가 충돌하면 최신 문서의 상태 표기와 근거를 검토한다.
- 과거 보고서의 반복 문장을 독립된 근거로 세지 않는다.
- 보관 문서에서 미검증 수치나 가설을 발견하면 현재 프로젝트 상태 문서의 보류 목록과 대조한다.

이번 반영에서는 ZIP 원본을 직접 추출할 수 없어 확인 가능한 원본 Markdown 자료를 별도 `research/` 경로에 보존한다. 바이너리 ZIP 전체의 내부 파일명과 체크섬을 검증했다고 주장하지 않는다.
