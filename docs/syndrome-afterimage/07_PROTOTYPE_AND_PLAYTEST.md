# 최소 프로토타입 및 플레이테스트

## 목적

현재 실험의 목적은 전체 게임을 만드는 것이 아니라, 단서 조사와 결과 피드백이 플레이어에게 이해되는지 확인하는 것이다. 이 단계에서 재미·공포·몰입을 확정적으로 측정한다고 주장하지 않는다.

## 첫 프로토타입 범위

- 작은 방 또는 한 화면
- 상호작용 대상 2–4개
- 서로 비교할 단서 2–3개
- 행동 뒤 바뀌는 텍스트/환경 반응 하나
- 재시작 동작 하나
- 엔진·카메라·스토리·엔딩은 확정하지 않음

추격, 복잡한 적 AI, 큰 인벤토리, 다수의 스테이지, 온라인 백엔드, 고빈도 왜곡 효과는 첫 실험에서 제외한다.

## 관찰할 질문

1. 설명 없이도 상호작용 가능한 대상을 알아차리는가?
2. 단서가 무엇을 의미한다고 생각하는가?
3. 행동 뒤 무엇이 바뀌었는지 설명할 수 있는가?
4. 다음 행동을 추론하는가, 아니면 막힌 이유를 구체적으로 말할 수 있는가?
5. 반응이 단서와 연결되어 있다고 이해하는가?
6. 텍스트나 효과가 정보를 가리거나 읽기를 방해하는가?
7. 선택지를 추가했다면 무엇을 의도했고 결과가 무엇을 바꿨다고 생각하는가?

## 테스트 진행

1. 실험 질문을 하나만 정한다.
2. 빌드와 테스트 조건을 기록한다.
3. 참가자에게 목표만 설명하고 해결법은 알려주지 않는다.
4. 관찰 가능한 행동과 발언을 기록한다. 추측을 사실처럼 적지 않는다.
5. 끝난 뒤 플레이어에게 이해한 규칙과 혼란스러운 지점을 설명하게 한다.
6. 관찰 결과를 근거로 수정하거나 보류한다.
7. 다음 실험은 한 번에 하나의 주요 변수를 바꾼다.

## 사전 등록할 임시 기준

숫자 임계값이 필요하면 실험 전에 임시 가설로 표시한다. 표본이 작으면 결과를 일반화하지 않는다. “대부분의 플레이어가 이해한다”와 같은 문장은 실제 참가자 수·상황·관찰 결과를 함께 제시할 때만 쓴다.
