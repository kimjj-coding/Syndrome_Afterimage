# 핵심 플레이 루프 비교 — 설계 가설

## 조사 질문

이 프로젝트는 탐색, 환경 단서, 퍼즐, 위협·회피, 대화, 선택을 검토해 왔다. 중요한 질문은 “이 기능을 모두 넣을까?”가 아니라 **초보자가 완성할 수 있는 규모에서 어떤 반복 행동이 핵심 경험을 만들어 내는가?** 이다.

아래 세 루프는 최종 추천이 아니라 비교 실험 후보다. 공식 게임 소개는 해당 작품의 표방 기능을 확인하는 데 쓸 수 있지만 보편적인 재미 법칙을 증명하지는 않는다.

## 후보 A — 탐색 → 단서 해석 → 세계 반응

1. 작은 공간에 들어간다.
2. 물체나 환경의 이상한 점을 발견한다.
3. 하나 또는 두 개의 단서를 조사·비교한다.
4. 환경이나 텍스트가 변한다.
5. 다음에 조사할 대상을 선택한다.

**가설:** 위협 AI 없이 환경 단서와 추론 경험을 가장 적은 복잡도로 시험할 수 있다.  
**주요 위험:** 사건의 변화나 목표가 없으면 단순한 클릭 반복처럼 느껴질 수 있다.

## 후보 B — 탐색 → 짧은 위협·회피 → 안전 구역 → 단서 해석

1. 탐색 중 단서를 발견한다.
2. 짧게 연출된 위협으로 즉각적인 목표가 바뀐다.
3. 플레이어가 읽을 수 있는 장애물이나 안전한 경로를 선택한다.
4. 안전 구역에서 단서의 의미가 확장되거나 달라진다.
5. 반응을 통해 배운 내용이나 선택의 결과를 확인한다.

**가설:** 조사 중간의 위협이 긴장감을 높이고, 장소를 더 취약하게 느끼도록 만들 수 있다.  
**주요 위험:** 충돌·재시작 로직, 위험 예고, 애니메이션·사운드 제작, 입력 접근성, 실패의 공정성, 단서 이해 방해.

## 후보 C — 상충하는 정보 → 해석/대응 선택 → 반응

1. 인물·문서·환경이 불완전하거나 모순되는 정보를 제시한다.
2. 플레이어는 두 가지 그럴듯한 해석이나 대응 중 하나를 선택한다.
3. 대화·방의 일부·다음 단서가 바뀐다.
4. 나중에 선택이 왜 중요했는지 되짚을 근거를 얻는다.

**가설:** 추격 없이도 해석의 불확실성과 결과의 무게를 만들 수 있다.  
**주요 위험:** 텍스트 양, 상태 복잡도, 분기 모순, 피드백 부족으로 인해 결과가 무작위처럼 느껴질 가능성.

## 비교표

평가는 과학적 측정값이 아니라 기획 단계의 질적 비교다. 프로토타입 결과에 따라 재평가해야 한다.

| 기준 | A — 단서 | B — 단서+회피 | C — 선택 |
|---|---|---|---|
| 핵심 행동 | 관찰·조사·비교 | 관찰·회피·회복·해석 | 읽기·듣기·해석·결정 |
| 긴장 원천 | 불완전한 정보와 바뀐 맥락 | 시간 압박과 정보 부족의 결합 | 의도와 결과의 불확실성 |
| 제작 부담 | 낮음~중간 | 중간~높음: 장애물·애니메이션·실패/재시도 | 중간~높음: 대화·상태 규칙·반응 작성 |
| 기술 부담 | 낮음~중간 | 시간 처리·충돌·재설정 때문에 더 높음 | 상태 전이와 일관성 검사 필요 |
| 테스트 명확성 | 단서가 무엇을 바꿨는지 설명 가능한가 | 위험이 공정하고 단서 이해를 방해하지 않는가 | 선택의 의도와 결과를 설명 가능한가 |
| 접근성 위험 | 텍스트·조사 대상 식별 | 반응 시간·운동 입력·위험 예고가 추가됨 | 읽기 속도와 선택 조작 |
| 대표 실패 | 정적이거나 모호함 | 불공정한 미니게임처럼 느껴짐 | 결과가 자의적이거나 무작위로 보임 |
| MVP 상태 | **먼저 시험** | **선택적 비교 실험** | **기본 루프 다음에 시험** |

## 권장하는 실험 순서

1. 후보 A를 먼저 시험해 단서와 피드백이 이해되는지 확인한다.
2. A가 이해 가능한 상태가 된 뒤 “위협이 긴장감을 더하는가, 단서 이해를 방해하는가?”가 여전히 중요한 질문이면 후보 B를 만든다.
3. 후보 C는 긴 분기 트리 대신 작은 상태 변경으로 먼저 시험한다.
4. 플레이어가 한 말·선택·행동·예상·이유를 관찰한다. “재미있었나요?”라는 질문 하나만으로 결정하지 않는다.
5. 추격이 들어간 프로토타입도 핵심 경험에 실패할 수 있다. 기능의 존재와 기능의 성공은 별개다.

## 엔진·카메라 독립 최소 범위

- 작은 방 또는 한 화면.
- 상호작용 대상 2~4개.
- 비교가 필요한 단서 2~3개.
- 행동 후 확인할 수 있는 세계/텍스트 반응 하나.
- 재시작 방법 하나.
- 선택형 실험을 할 경우, 엔딩이 아닌 작은 반응을 바꾸는 두 선택지.
- 제외: 복잡한 적 AI, 큰 인벤토리, 여러 스테이지, 여러 엔딩, 온라인 백엔드, 높은 빈도의 왜곡 효과.

## 성공 여부를 판단하는 질문

- 설명을 미리 듣지 않아도 쓸모 있는 단서를 하나 이상 찾았는가?
- 행동 뒤 무엇이 바뀌었는지 말할 수 있었는가?
- 다음 행동을 추론했는가, 아니면 막힌 이유를 구체적으로 말할 수 있었는가?
- 상호작용이 단순한 연속 클릭보다 의미 있었는가?
- 시각·청각 효과가 정보를 가리거나 불편함을 일으켰는가?
- 선택이 있었다면, 무엇을 의도했고 결과가 무엇을 바꿨는지 이해했는가?
- 다음 기능은 핵심 경험 검증에 필요한가, 아니면 단지 멋있어 보이는가?

숫자 기준을 쓰려면 첫 테스트 전에 임시 가설이라고 표시하고, 실제 관찰 후 수정한다. 업계 표준인 것처럼 임의의 수치를 만들어 내지 않는다.
