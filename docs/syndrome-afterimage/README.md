## 현재 유지해야 할 원칙

- 이 프로젝트는 웹 브라우저 게임이다. 네이티브 앱·콘솔 게임으로 바꾸지 않는다.
- 엔진, 카메라, 조작, 스토리, 주인공, 변수 모델, 엔딩 수는 미확정이다.
- 확인된 사실, 출처 기반 해석, 실험 가설, 보류 결정을 분리한다.
- 게임의 공식 소개는 작품이 표방하는 기능을 확인하는 자료이지, 그 기능이 재미·공포·몰입을 높인다는 증명은 아니다.
- 반복 복사된 문장은 독립된 증거 여러 개로 계산하지 않는다.
- MBV/RI, 수치 임계값, `뒤돌아보기 +5`, 6개 엔딩은 검증된 사실이 아니다.
- 정신건강 진단을 도덕성·폭력성·엔딩 점수로 사용하지 않는다.
- 프로토타입이나 플레이테스트를 하지 않았다면 검증 완료로 보고하지 않는다.

## 상태 표기

- **확인됨:** 적절한 출처 또는 반복 가능한 테스트가 해당 범위의 주장을 뒷받침함.
- **해석:** 자료에서 도출한 분석이며 보편 법칙이 아님.
- **가설:** 이 프로젝트에서 실험해야 함.
- **보류:** 아직 구현하거나 확정된 결론처럼 사용하지 않음.
- **폐기:** 명시적인 재검토 없이는 이어받지 않음.

## 가장 가까운 다음 작업

작은 공간에서 상호작용 대상 2–4개, 단서 2–3개, 단서 조사 후 나타나는 관찰 가능한 반응 하나, 재시작 기능만으로 핵심 루프를 시험한다. 추격·복수 엔딩·3D·복잡한 적 AI를 먼저 구현하지 않는다. 이 순서는 실험 우선순위이며 최종 장르나 기능 확정이 아니다.
